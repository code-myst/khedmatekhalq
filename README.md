# খেদমতে খালক বইয়ের দোকান (Next.js + WooCommerce)

পণ্য ও দাম WooCommerce Store API থেকে আসে। কার্ট ব্রাউজারে থাকে। "চেকআউটে যান" চাপলে
khedmatekhalq.com-এর WooCommerce চেকআউটে কার্টসহ চলে যায়।

এই সংস্করণে আছে: GSAP অ্যানিমেশন, lucide আইকন, নতুন হেডার/ফুটার, কার্ট ড্রয়ার,
ক্যাটাগরি ফিল্টার, সার্চ ও সর্টিং, ছবির গ্যালারি, সংশ্লিষ্ট বই।

## চালানো
    npm install
    npm run dev

## Vercel-এ ডেপ্লয়
